# 可直接钉钉推送的情报日报实施计划

1. 补齐页面发布日期证据桥接、融资主体规范化、同事件归并和 B 级媒体定向查询。
2. 为候选诊断增加报告所需的结构化字段，并实现“今日最值得看”和分类内分层线索。
3. 在分析完成后写入候选检查点；实现降级报告、异常告警、投递状态和失败语义。
4. 为手动 Actions 增加默认 dry-run 的 `delivery_mode`，真实测试只读取现有 DingTalk Secrets。
5. 增加单元、流水线、报告、CLI 和 workflow 测试，使用仓库内可写 basetemp 执行完整测试。
6. 推送当前分支，先运行 dry-run 并检查产物；严格核实至少一条且报告通过门槛后，再执行一次真实测试推送。
