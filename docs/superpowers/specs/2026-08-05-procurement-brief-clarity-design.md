# 招标采购短报清晰化设计

## 目标

钉钉短报的招标采购板块必须同时服务两个业务目的：

1. 快速识别当前仍可参与的投标机会，并明确投标截止时间；
2. 通过候选人公示、中标、成交、废标和终止等信息掌握行业动态。

短报不得继续展示带网站后缀的超长标题或截断的搜索摘要。所有内容采用结构化字段，缺失字段不得猜测。

## 展示结构

“二、招标采购情况”固定分为三个子区，顺序不变：

1. `🟢 可投标机会`
2. `🟡 需核实确认`
3. `🔵 结果与行业动态`

空分区显示一句简短说明，不显示统计摘要或网页原文。每个分区默认最多展示 3 条；需要压缩时优先减少每个分区的条数，而不是删除关键字段。

### 可投标机会

只有同时满足以下条件的项目才能进入该区：

- 公告阶段属于招标、询价、比选、重新招标，或带有新截止期的变更/延期公告；
- 投标截止时间来自页面正文证据；
- 截止时间按北京时间计算尚未到期；
- 项目方向属于激光通信、激光武器/反无人机或光电转塔/吊舱；
- 来源和可信状态满足现有展示规则。

按投标截止时间由近到远排序，同日截止时优先展示可信等级更高、公告更新更近的项目。
“剩余天数”按投标截止日期与当前北京时间日期的自然日差计算；截止日期为当天时统一显示“今日截止”。

固定展示字段：

- 项目名称；
- 采购方；
- 方向；
- 投标截止时间；
- 剩余天数或“今日截止”；
- 可信状态；
- 来源链接。

预算/最高限价、项目编号、报名截止时间为可选字段，仅在有证据时展示。

示例：

```markdown
### 🟢 可投标机会

**光电吊舱系统材料采购**
- 采购方：电子科技大学｜方向：光电转塔/吊舱
- 投标截止：2026-08-20 17:00｜剩余：15天
- 预算：87万元｜可信：已核实
- [查看官方公告]
```

### 需核实确认

该区只承载可能具有行动价值、但尚不足以安全判断“可投标”的线索，包括：

- 疑似招标、询价、比选、重新招标、变更或延期公告，但投标截止时间缺失；
- 公告类型、日期、采购方或截止时间存在冲突；
- 只有聚合站摘要，尚未找到官方原始公告；
- 截止时间已提取但缺少正文证据；
- 关键信息不足，无法判断是否已经截止。

按“疑似仍可参与”优先，其次按发布日期由近到远排序。不得使用绿色机会标识，也不得计算剩余天数。

固定展示字段：

- 清洗后的项目名称；
- 已知采购方和方向；
- 可能的公告阶段；
- 明确列出“待确认”字段；
- 可信状态；
- 官方来源或聚合线索链接。

示例：

```markdown
### 🟡 需核实确认

**无人机激光反制设备采购**
- 采购方：上海市公安局黄浦分局｜方向：激光武器/反无人机
- 疑似阶段：招标公告｜可信：候选线索
- 待确认：投标截止时间、官方原始公告
- [查看聚合线索]
```

### 结果与行业动态

该区展示已经进入结果或非当前投标阶段的信息：

- 采购意向；
- 评审中；
- 中标候选人公示；
- 中标或成交结果；
- 废标、终止和已关闭项目；
- 不再具备投标行动价值的历史变化。

按公告日期由近到远排序。该区的作用是了解采购方向、采购方、供应商和成交规模，不得标为“可投标”。

固定展示字段：

- 项目名称；
- 当前结果或阶段；
- 采购方；
- 公示日期；
- 可信状态；
- 来源链接。

中标/成交供应商、中标/成交金额、项目编号为可选字段，仅在正文明确披露且有证据时展示。

示例：

```markdown
### 🔵 结果与行业动态

**电子科技大学光电吊舱系统材料采购**
- 结果：已成交｜公示日期：2026-07-30
- 采购方：电子科技大学｜成交供应商：某某科技
- 成交金额：86万元｜可信：已核实
- [查看结果公告]
```

## 字段与数据流

现有正式 `Project`/`Event` 已能保存公告阶段、采购方、金额和截止期；候选诊断目前只保存标题、摘要、采购方、日期和金额，导致候选条目只能回退到原始摘要。

改造后需要把以下分析结果传递到候选诊断和短报信号：

- `event_type`；
- `registration_deadline`；
- `bid_submission_deadline`；
- `opening_deadline`；
- `deadline_precision`；
- 每个截止时间对应的证据状态；
- `awarded_supplier`（可选）；
- `awarded_amount`（可选；不得与预算混用）。

数据流保持单向：正文分析 → 候选诊断/正式事件 → 招标展示分类器 → 三个渲染分区。渲染器不从自由文本重新猜测字段。

## 标题清洗与排版

- 删除站点名、频道名、重复的“官网”“招投标公共服务平台”等后缀；
- 保留项目主体、标段或批次以及公告阶段所需信息；
- 搜索摘要不直接进入钉钉正文；
- 每条使用两至四行固定字段，不拼成长句；
- 金额必须带业务语义：`预算`、`最高限价`、`中标金额`或`成交金额`；
- 链接按来源性质标记为“查看官方公告”“查看结果公告”或“查看聚合线索”。

## 失败与降级规则

- 截止时间解析失败或证据不足：进入“需核实确认”，不得进入“可投标机会”；
- 公告阶段冲突：进入“需核实确认”，并显示待确认项；
- 已超过投标截止时间但尚无结果：进入“结果与行业动态”，状态显示“已截止，结果待跟踪”；
- 钉钉长度不足：每区从 3 条降至 2 条、再降至 1 条；关键字段和来源链接不可截断；
- 候选快照降级报告继续遵守三分区规则，不把搜索摘要原样发送。

## 测试与验收

必须覆盖以下场景：

1. 有正文证据且未截止的招标进入“可投标机会”；
2. 当日截止在当天结束前仍显示为机会，并标记“今日截止”；
3. 已过期项目不进入机会区；
4. 截止时间缺失、无证据或冲突时进入“需核实确认”；
5. 中标、成交、候选人、废标、终止进入“结果与行业动态”；
6. 中标供应商和金额只在正文明确披露时展示；
7. 标题清洗不会删除项目名、标段或批次；
8. 聚合站链接明确标为“查看聚合线索”；
9. 招标预算不会进入融资统计，融资金额也不会进入招标字段；
10. 三分区压缩后仍保留项目名、状态/截止期和来源链接；
11. 现有严格核实标准、每日查询预算、定时投递和当天去重行为保持不变。

验收效果是：用户在手机上无需阅读原始摘要，即可在一分钟内区分当前机会、待确认线索和已结束的行业动态，并能点击可追溯来源继续判断。
